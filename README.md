# NeuroGoru UI

Frontend-only PySide6 prototype for a smart livestock monitoring dashboard.
All values, alerts, device states, map markers, and charts are simulated.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

There is no hardware, network, database, API, serial, or backend integration.
